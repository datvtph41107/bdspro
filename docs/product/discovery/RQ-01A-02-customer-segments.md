### Source comparison: why Gitea is a reference, not a requirement
[Gitea 1.24 permissions](https://docs.gitea.com/1.24/usage/permissions/) documents individual/org repository ownership, owner team, team-scoped repository access and permissions. At v1.24.0 commit 7ed1e8987eb5da50b3ad5e3e863903cce45565b6, [user.go L45–52](https://github.com/go-gitea/gitea/blob/7ed1e8987eb5da50b3ad5e3e863903cce45565b6/models/user/user.go#L45-L52) defines individual/org user types; [org.go L78](https://github.com/go-gitea/gitea/blob/7ed1e8987eb5da50b3ad5e3e863903cce45565b6/models/organization/org.go#L78) defines Organization with User underlying type; [CreateOrganization L284–343](https://github.com/go-gitea/gitea/blob/7ed1e8987eb5da50b3ad5e3e863903cce45565b6/models/organization/org.go#L284-L343) sets org type and prepares owner team. Source and documented product semantics establish implementation, not historical rationale or BDSPro applicability.
BDSPro baseline accounts/membership and team routes above represent different design assumptions. Preserve existing contracts; no delete/add tables, mandatory org, DI/global refactor or auth implementation from this checkpoint. Investigate when a chosen workflow warrants it.

### Bounded research scenario and counterexamples
Hypothesis: a broker receives authorized property information, maintains several records, selects information for public listing, and a seeker finds a listing and contacts through an agreed method. A private note must not accidentally become public. Record creation does not prove title or authority; publication permission must be clarified. Alternatives: owner self-publishes; company employee acts on delegated inventory. If real policy requires company-controlled records or offboarding, revisit membership/data scope; if only a personal workspace is needed, do not add company administration just to model a possible future. If public contact causes material abuse or a specific lead workflow requires verification, evaluate proportionate controls and friction; do not mandate OTP/KYC today.
