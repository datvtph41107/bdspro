# R07 — Email-link persistence in models/account

Gitea reference: `go-gitea/gitea@12b20c7` model operation ownership.

- `models/account.BeginEmailLink` owns the account row lock, address uniqueness, challenge upsert and resend cooldown.
- `models/account.ConfirmEmailLink` atomically consumes a one-use proof and attaches a verified email to the same account.
- `services/auth` retains email syntax validation, reauthentication via phone OTP, email sending and the public error contract. No change in Gin, routes or public API.
- The PostgreSQL integration test checks address collision, resend cooldown, incorrect proof, successful same-account attachment, and replay denial.
- All SQL remains generated by SQLC. No migration, ORM or new transaction mechanism.
- OTP remains in its specialized pgx transaction implementation because incorrect-code attempts must commit the failure count.
