Các file dưới đây là **nguồn hướng dẫn đang hoạt động** từ 11/10/2026. Đọc theo thứ tự:

1. [Tổng kết giai đoạn CORE-01 → CORE-05](BAO-CAO-GIAI-DOAN-CORE-01-05.md) — cái gì đã làm, cái gì được chứng minh, cái gì chưa.
2. [Quy trình và phong cách làm việc](QUY-TRINH-LAM-VIEC.md) — cách phân tích, code, test, commit và bàn giao.
3. [Thiết kế/ảnh hưởng/bất biến](CORE-01-TO-05.md) — lý do chọn kiến trúc, phương án thay thế, chi phí và rủi ro.
4. [Đồng bộ và nghiệm thu trên local](LOCAL-ACCEPTANCE.md) — thao tác thực hiện, các ca phản chứng.
5. [Checkpoint](../continuity/CHECKPOINT.md) và [prompt tiếp tục](../continuity/TIEP-TUC-CORE-01-05.md).
